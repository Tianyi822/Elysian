Source components copied and adapted under src/components/easyui/:
- StatCard.tsx (including pointer/keyboard scrubber, spring cursor and SVG chart)
- Button.tsx (variants, loading state and spring press feedback)
- Badge.tsx (variants, status dot and optional animated content)
- PillNavigation.tsx (global page tabs, toolbar/form segments and shared-layout selection)
- NotificationBell.tsx (extracted bell trigger, arrival shake and unread dot)
- LiquidToggle.tsx (controlled SVG blob switch and spring deformation)
- SlidePagination.tsx (page range and shared-layout sliding indicator)
- Supporting chart primitives, monotone path utility, motion tokens and cn utility

Upstream paths, revision and adaptation boundaries are recorded in
src/components/easyui/upstream.json. Elysian adapters retain existing API data,
Chinese labels, theme tokens, accessibility and reduced-motion preferences.
